# Stack Moxie

> Stack Moxie is a revenue-observability platform providing automated testing and monitoring for AI, marketing, and RevOps technology stacks. It watches integrated SaaS platforms end to end, catches outages, broken automations, and email-deliverability issues before they become revenue incidents, and QAs campaign launches. Two developer surfaces: a hosted REST API (OpenAPI 3.0.1, 43 operations, JWT bearer auth) for driving test scenarios programmatically, and the open-source Crank CLI with its ecosystem of gRPC "Cog" plugins for running the same tests locally.

Stack Moxie does not publish an llms.txt of its own; this file is generated by API Evangelist from the provider's public surface and the artifacts in this repository. Fetched and verified 2026-08-14.

## API

- [Stack Moxie REST API reference](https://api.stackmoxie.com/): ReDoc reference for the hosted API. The full OpenAPI 3.0.1 document is embedded in this page — there is no raw .json or .yaml URL.
- Base URL: `https://app.stackmoxie.com/api/` — all paths prefixed `/v1/`, all operations scoped to an Organization UUID (`/v1/organizations/{org}/...`).
- Authentication: `Authorization: Bearer <jwt>`, applied globally to all 43 operations. Tokens are minted and revoked on the account settings page at https://app.stackmoxie.com; there is no token, refresh, or introspection endpoint.
- Capabilities: Scenarios (create/run/schedule tests), Runs and Run Logs, async Scenario submission with job polling, Connections (stored per-Cog credentials for Salesforce, Marketo, Pardot, Eloqua, Dynamics, HubSpot), the Cog registry, Folders, Schedules, Notification Groups, Organizations and Members.
- No webhooks, no callbacks, no event stream. Async completion is discovered by polling `GET /v1/organizations/{org}/job/{jobId}`.
- No documented rate limits and no `429`; the real ceiling is the monthly "run" quota on your plan.
- No `Idempotency-Key`: a retried run POST executes a second real test against live systems and consumes a second metered run.

## Open source

- [Crank](https://crank.run): open-source, no-code BDD test suite for integrated enterprise SaaS. Install: `curl -s https://get.crank.run/install.sh | sh`.
- [Crank CLI (GitHub)](https://github.com/run-crank/cli): the `crank` runner. Last tagged release v0.11.1 (2020-06-23).
- [run-crank GitHub org](https://github.com/run-crank): the CLI plus 25+ platform Cogs (Salesforce, Marketo, Pardot, Eloqua, SFMC, OpenAI, Anthropic, Gemini, web, inbox, DNS, and more).
- [Cog images on Docker Hub](https://hub.docker.com/u/automatoninc): 19 public images. Note their `latest` tags were last pushed in 2019–2020 and seven carry no `latest` tag at all.
